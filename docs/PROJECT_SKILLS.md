# Chess for Xiaomi Vela — 项目 Skill 总结清单

## 当前具备的核心能力

1. **Vela JS 快应用能力**：使用 `.ux` 页面、`manifest.json`、Vela 系统模块和 AIoT Toolkit 构建可安装的 RPK。
2. **Xiaomi Band 9 适配能力**：以 192dp × 490dp 窄长屏为设计基准，使用 dp 单位和手环友好的竖向布局。
3. **离线双人棋局能力**：两名玩家可以在同一只手环上轮流操作同一盘棋。
4. **棋盘交互能力**：棋子选择、合法落子提示、棋盘拖动、棋盘缩放、选中后自动居中。
5. **西洋棋规则能力**：基础走子、吃子、将军、将死、逼和、王车易位、吃过路兵、兵升变、无足够子力、五十回合和三次重复局面判定。
6. **棋局控制能力**：悔棋、认输、和棋、重新开始、退出对局、结果查看和终局锁定。
7. **计时能力**：双方独立倒计时、走子后切换计时方、超时结束、终局停止计时。
8. **配置能力**：走法提示、自动居中、认输确认、棋盘动画和棋盘大小设置。
9. **手环性能能力**：使用 PNG 棋子资源、触摸帧节流和合法走法缓存，降低窄屏设备上的重复计算和重绘。
10. **资源兼容能力**：棋子使用 PNG 位图，避免在 Vela 设备上依赖 SVG 动态解析。
11. **版本回溯能力**：每次重要修复保存独立 RPK 文件名和源码快照。
12. **桥接扩展能力**：保留 SimpleFetch/interconnect 桥接和网页搜索代码，为未来网络功能预留扩展点。

## 尚未完成或需要继续验证的能力

- 标准 PGN/棋谱记录与历史棋局列表。
- 对局二维码生成与分享。
- 少于 8 回合不保存、达到条件后保存的历史策略。
- 升变时选择后、车、象、马，而不是固定升变为后。
- 更严格的 FIDE 规则边界验证和自动化规则测试。
- 真机上对所有极端终局、休眠唤醒和快速连续点击的完整回归测试。
