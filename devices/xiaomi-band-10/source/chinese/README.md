# Xiaomi Smart Band 10 Chess — 中文源码

完整、可独立构建的 Xiaomi Vela JS 快应用中文源码，目标设备为 Xiaomi Smart Band 10。

- 屏幕基准：212×520 / 212dp
- 包名：`com.xykadi.chess`
- 版本：`1.0.0` / version code `100`
- 源码语言：中文界面

在本目录构建：

```bash
npm ci --cache .npm-cache
npm run build
```

英文源码位于同级目录 [`../english`](../english)。构建时不要混用两个 `src/` 目录。
