# Xiaomi Smart Band 10 Chess — English Source

Complete independently buildable English Xiaomi Vela JS quick-app source for Xiaomi Smart Band 10.

- Screen baseline: 212×520 / 212dp
- Package: `com.xykadi.chess`
- Version: `1.0.0` / version code `100`
- Source language: English UI

Build from this directory:

```bash
npm ci --cache .npm-cache
npm run build
```

The Chinese source is a separate sibling directory at [`../chinese`](../chinese). Do not mix the two `src/` trees when building.
