# Archive

本目录保存不参与当前 Vela 构建的历史资料和发布产物。

- `history-20260925.tar.gz`：历史源码快照、用户原始上传源码和早期源码归档。
- `diagnostics-20260925.tar.gz`：Band 9 原机诊断包和烟雾测试资料。
- `dist/`：历史 0.2.x RPK 构建产物以及早期 1.0.0 构建产物。
- `exports/`：历史版本源码包和构建工程包。
- `releases/`：当前及历史 RPK、源码归档和 SHA-256 文件。
- `source-uploads/`：用户提供的原始源码压缩包。

这些文件仅用于回溯、比对和发布追踪。当前构建只使用仓库根目录的 `src/`、`tools/`、`package.json`、`package-lock.json` 和 `.npmrc`。
