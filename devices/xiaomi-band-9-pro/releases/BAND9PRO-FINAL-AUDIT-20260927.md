# Xiaomi Smart Band 9 Pro 最终适配审计

## 目标设备

- 屏幕：336×480 像素
- Vela 快应用设备类型：`watch`
- 设计宽度：`336dp`
- 页面画布：`336dp × 480dp`

## 已检查项目

- manifest 的 package、版本、入口、路由和 `designWidth`
- 首页、准备页、棋局页、设置页、关于页、支持页、购买页 UX 脚本语法
- 192×490 和 212×520 旧画布引用清理
- 336dp 棋盘水平居中、拖动边界和触摸坐标
- 关于页/支持页外层高度：`52 + 428 = 480dp`
- 购买页外层高度：`52 + 364 + 64 = 480dp`
- 棋局页外层高度：`48 + 26 + 280 + 46 + 58 = 458dp`
- 购买页二维码、价格、Token、项目说明卡片的内部高度
- 关于页二维码卡片的内部高度
- 支持页二维码和返回按钮的内部高度
- 图标、开发者头像、爱发电二维码和全部棋子资源
- RPK ZIP 完整性和资源是否进入 RPK
- 编译证书与私钥公钥是否匹配

## 结果

所有静态检查、布局溢出审计、源码语法检查和 RPK 完整性检查均通过。

JSC 和 Protobuf 保持默认关闭，避免设备启动兼容性问题。

签名私钥没有写入源码归档、RPK 交付目录或 Git 版本库。
