# Chess Smoke 0.0.1

这是用于 Xiaomi Band 9 真机分流诊断的独立 RPK，不是正式棋局版本。

它保留首页、开始对局页和完整路由，但 game 页面替换为极简页面：无棋盘、无棋规、无计时、无 storage、无动态 64 格节点、无 PGN 和 overlay。

测试步骤：

1. 安装 `com.codex.test.chess.smoke.debug.0.0.1.rpk`。
2. 从首页点击“开始游戏”。
3. 在开始对局页选择任意时间。
4. 点击“开始下棋”。
5. 观察是否显示“棋局页面已打开”。

判断：

- 能打开：路由和基础页面 VM 正常，正式版问题主要在 game 页面创建/渲染峰值；下一步拆分正式 game 页。
- 仍重启：优先排查 RPK 安装缓存、Vela/手环固件兼容性、同包旧版本残留和基础页面路由，而不是棋规算法。
