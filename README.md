# Vela Chess

小米 Vela JS 快应用原型，面向 Xiaomi Band 9 的离线单设备双人轮流下棋。

## 当前功能

- 8×8 国际象棋棋盘，放大后支持横向/纵向平移。
- 点击棋子显示当前实现的合法目标点，再点击目标点落子。
- 白方/黑方轮流状态、最后一步高亮、选中格高亮和走子震动位预留。
- 悔棋、认输、再来一局、设置页。
- 走法提示、自动居中、认输确认三个棋局设置。
- 纯本地状态，不需要网络、账号或手机伴侣。

## 在 AIoT-IDE 中运行

1. 用 AIoT-IDE 打开本目录。
2. 创建或选择 `watch` 模拟器。
3. 使用调试按钮启动快应用。
4. 在真机上重点验证棋盘触摸坐标、横向平移和圆屏裁切。

## 当前原型边界

当前走法提示已覆盖兵、马、象、车、后、王的基本移动与吃子，作为 UI/交互原型使用。正式发布前还需要补齐王车易位、吃过路兵、兵升变、将军约束、三次重复和五十回合规则，并将棋局状态接入 `@system.storage` 做应用重启恢复。

ResonaUI 的仓库内容在当前环境未能稳定读取，因此本原型采用兼容 Vela 的深色卡片和圆角按钮风格，避免引入未经 Vela 真机验证的 Web 依赖。
